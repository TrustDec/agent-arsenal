## ✨ 垂直技术栈专属严苛规范

- 🧠 **Agentic 持续学习、Reflexion 反思闭环与动态规则提炼生产级规范 (`rules/agentic-reflexion-continuous-learning-distillation.md`)**：面向长程自主编码与结对编程 Agent（Claude Code、Cursor Composer、Windsurf Cascade、Roo Code、Pi、OpenCode、Aider 等）彻底终结“失忆 Agent 陷阱”（Amnesiac Agent Trap：每轮会话从零起步、重复踩坑已知编译器报错与接口陷阱、重复消耗海量 Token 与人力解释成本）与“反向顺从临时补丁污染”（Sycophantic Workaround Curse：大模型为通过编译擅自加 `@ts-ignore`、`any`、`--no-verify` 或跳过测试，并将其错误提炼为持久规则毒化仓库）；将**内部执行循环**（ReAct 工具调用、编译构建与测试验证）同**外部不变量反思提炼循环**（Reflexion 事后根因归因、反毒化过滤与分级规则晋升）物理级解耦；四阶段 Reflexion 反思提炼流水线（认识论鸿沟与异常阻断检测 $\to$ 反事实因果归因隔离错误心智模型 $\to$ 标准 Agent Arsenal 不变量模式合成 $\to$ 反毒化与泛化防火墙）；三级生活工作区记忆阶梯（Tier 1 轮次临时草稿 `activeContext.md`/`decisionLog.md` 分支合入即清空 $\to$ Tier 2 候选规则暂存区 `.agents/candidates/<slug>.md` 记录命中计数与复现命令 $\to$ Tier 3 权威仓库法则 `CLAUDE.md`/`.cursorrules`/`rules/*.md` 需经 $\ge 3$ 次独立会话验证或人工 PR 签署晋升）；六重绝对禁止的规则反毒化防火墙（严禁固化 `@ts-ignore`/`any`/`--no-verify`/跳过测试等劣质补丁、剔除网络超时与端口占用等环境瞬态干扰、规则语义去重与冲突检测、精准 AST/Glob/正则触发限制严禁通配符、强制提供机器可验证的测试/构建命令、硬限 400 词高密度零废话预算）；生产级 TypeScript `TrajectoryReflexionDistiller` 轨迹提炼引擎、Reflexion 轨迹有限状态机（FSM），以及六重机器可验证 Definition of Done (DoD) 验收门禁。
- 💻 **Agentic 代码即动作 (CodeAct)、REPL 驱动工具编排与编程式上下文压缩生产级规范 (`rules/agentic-code-execution-repl-codeact.md`)**：面向自主编码与终端交互 Agent（Claude Code、Cursor Composer、Windsurf Cascade、Roo Code、Pi、OpenCode、SWE-agent、smolagents 等）彻底终结“JSON 工具调用瓶颈”（JSON Tool-Calling Trap）与 $O(N)$ 上下文单体税；以图灵完备的状态化代码执行（Python、Node.js、Bash）替代脆弱碎片化的多轮函数调用；源头过滤铁律（Filter-at-Source Law：对兆字节级的 API 响应、数据库结果集、日志流与 DOM 树在 REPL 内存中直接完成过滤、聚合与投影，仅向大模型上下文吐出高密度摘要，暴降 90%~98% Token 消耗与推理延迟）；状态化 REPL 会话命名空间持久化（跨轮次长效保留变量、模块导入、数据库连接池与辅助函数，根绝每轮重复认证与磁盘序列化开销）；双缓冲区截断与草稿外溢协议（Dual-Buffer Spillover：硬限 2000 行 / 50KB 标准输出，保留首尾关键帧并将全量日志外溢写入 `/tmp/agent_scratchpad_*.log`）；编程式工具组合与本地高并发（基于 `asyncio.gather` 与线程池在代码内完成多节点扫描与指数退避重试，杜绝数十轮 LLM 串行等待）；绝对非交互式执行保证（`DEBIAN_FRONTEND=noninteractive`、禁用 `input()`、自动注入免交互确认参数）；确定性报错堆栈外科手术式分流（剥离上百行框架内部调用栈，仅保留目标行与异常根因）；五步 CodeAct 自愈有限状态机（FSM），以及六重机器可验证 Definition of Done (DoD) 验收门禁。
- 🧪 **Agentic 测试驱动开发 (TDD)、基于属性的测试 (PBT) 与变异测试强化生产级规范 (`rules/agentic-tdd-property-testing-mutation.md`)**：面向长程自主编码 Agent（Claude Code、Cursor Composer、Windsurf Cascade、Roo Code、Pi、OpenCode、SWE-bench 等）彻底终结“盲目推测式编码”（Speculative Coding）与“事后追补测试幻觉”（Retrofit Mirage：先写 300 行脆弱业务逻辑，再凭幻觉反推虚假测试）；五阶段 Agentic TDD 有限状态机（不变量建模 $\to$ 机器执行证明 RED 阻断门禁 $\to$ 最小化外科手术 GREEN 阶段 $\to$ 无菌室静态重构 REFACTOR $\to$ 变异强化与模糊测试）；五大数学不变量综合分类学（可逆往返不变量 $f^{-1}(f(x)) \equiv x$、幂等性不变量 $f(f(x)) \equiv f(x)$、资源守恒定律 $\sum \text{资产}_{t_0} \equiv \sum \text{资产}_{t_1}$、单调递增不变量 $x_1 \le x_2 \implies f(x_1) \le f(x_2)$ 与变态不变量 Metamorphic Invariance）；现代多语言全栈基于属性的测试（PBT）生成器工程（TypeScript `fast-check`、Go `pgregory.net/rapid`、Python `hypothesis` 与 Rust `proptest`）配合自动化收缩（Shrinking）精准定位最小反例；变异测试（Mutation Testing）与反顺从击杀率硬指标（$M_k = \frac{\text{击杀数}}{\text{总变异体} - \text{等价变异体}} \ge 85\%$，基于 Stryker、mutmut、go-mutesting 杜绝看似 100% 行覆盖率实则零断言的虚假测试）；六项绝对禁止的测试掩盖禁令（严禁迎合错误代码擅自弱化下调测试期望、严禁 `toBeDefined()` 无意义同义反复断言、严禁跳过或删除失败测试、严禁对被测目标本身过度 Mock、严禁使用真实物理时钟睡眠，以及严禁在测试文件中使用 `@ts-ignore` 掩盖类型错误），以及机器可验证的 Definition of Done (DoD) 验收门禁。
- 📋 **Agentic 规格驱动开发 (SDD)、动态生活记忆库 (Memory Bank) 与架构决策记录 (ADR) 生产级规范 (`rules/agentic-spec-driven-development-memory-banks.md`)**：面向长程复杂多轮自主开发任务（Claude Code、Cursor Composer、Windsurf Cascade、Roo Code、Pi、OpenCode 等 50+ 轮工程），彻底终结“盲目即兴发挥”（Wandering Improviser：中途偏离初始需求、遗漏边界条件、临场改换技术栈、随意篡改接口契约）与“目标失忆症”（Objective Amnesia）；将**意图与架构设计**（Intent & Architecture）同**代码生成**物理级解耦；标准七文件动态生活记忆库规范（`projectBrief.md` 顶层使命与边界锁死、`productContext.md` 用户旅程与领域词汇、`systemPatterns.md` 拓扑边界与严禁反模式、`techContext.md` 密闭工具链与编译器版本、`activeContext.md` 当前活跃轮次假设与唯一即时动作、`progress.md` 机器可验证的任务看板与 DoD 清单、`decisionLog.md` 架构决策历史）；标准 MADR 架构决策记录格式（强制先立项记录上下文、决策驱动因素、备选方案优劣与爆炸半径，方可触碰业务代码）；规格不可变性公理（Spec Invariance Axiom：代码必须服从规格，严禁因遇到报错而擅自降级需求或弱化修改测试断言）；契约优先设计（Contract-First：Zod、TypeScript、OpenAPI、Protobuf 与 SQL DDL 强类型输入输出边界防线）；六重机器可验证 Definition of Done (DoD) 矩阵（类型静态检查 $\to$ 代码规范 Linter $\to$ 验收测试 $\to$ 干净 Git 树 $\to$ 记忆库对齐 $\to$ 终端证明日志），以及生产级 TypeScript 记忆库守护网关引擎。
- 🛑 **Agentic 人机协同 (HITL)、动态权限分级与爆炸半径治理生产级规范 (`rules/agentic-hitl-permission-blast-radius.md`)**：面向自主终端执行、文件改写、数据库变更与网络出向的编码 Agent（Claude Code、Cursor Composer、Windsurf Cascade、Pi、OpenCode、Roo Code、LangGraph），彻底解决“自主失控恶性循环”（Runaway Loop：误删文件、强制推流、拖库炸库）与“确认疲劳瘫痪”（Prompt Fatigue：微小操作频繁弹窗致使开发者机械同意）；五级动作风险分级矩阵（Tier 0 纯环境只读自动放行、Tier 1 幂等本地验证静默审计放行、Tier 2 可逆本地变更有上限放行并附带 Git 快照、Tier 3 不可逆本地破坏性操作强制交互式 HITL 弹窗确认、Tier 4 外部网络出向与云基础设施变更强制密码级显式确认）；量化爆炸半径算法（$B = w_f \cdot \Delta F + w_l \cdot (\Delta L_{\text{add}} + \Delta L_{\text{del}}) + w_s \cdot S_{\text{scope}} + w_e \cdot E_{\text{egress}}$）与硬限额门禁（单轮触碰文件 $\le 10$、代码变动 $\le 300$ 行、根目录操作绝对阻断）；Shell 命令 AST 语法树解析与防绕过防火墙（基于 POSIX/tree-sitter 语法树深度检测命令拼接 `&&`、子 Shell 替换 `$(...)`、解释器管道 `| sh`、Base64 解码管道与 PATH 劫持，解析绝对二进制路径）；标准结构化 XML 审批协议与 60s 超时确定性默认阻断（Default-Deny）；无头 CI/CD 环境安全兜底机制；影子预检（数据库事务 `ROLLBACK` 语法验证与 Git 临时工作树隔离验证）；预写动作日志（WAL）与确定性逆向补偿回滚机制（Compensating Action Journal），以及高可用 TypeScript 动作防护网关引擎。
- 🧩 **Agentic Skills 技能架构、动态能力发现与分层渐进式披露生产级规范 (`rules/agentic-skills-progressive-disclosure.md`)**：面向长程工程与企业级多技能场景（Claude Code、Cursor Composer、Windsurf、Pi、OpenCode、Roo Code、Anthropic Agent Skills 规范）彻底终结 50+ 领域技能全量堆砌系统提示词导致的“单体上下文税”（Monolithic Context Tax）与“注意力迷失”（Lost-in-the-Middle）；三级渐进式披露架构（Tier 0 极简环境清单 Ambient Manifest 仅注入 `<name>`、`<description>`、`<location>`，单技能 <35 Token，百款技能仅占不到 3,500 Token，100% 保持 KV 缓存前缀命中；Tier 1 意图命中时通过 `read` 工具即时注水 Just-in-Time Hydration 全量指令与规约；Tier 2 关联引用资产与脚本动态执行；Tier 3 任务完成后即刻修剪中间输出并沉淀四段式事实检查点）；确定性触发契约与负向排除护栏（明确正向触发条件与负向路由边界，严禁无脑贪婪冒领）；绝对断言校验公理（Rule of Verification：严禁在未读取 `SKILL.md` 的情况下凭幻觉猜想或推断技能规约）；密闭路径解析与工作目录无关性纪律（全面基于 `dirname(SKILL.md)` 锚定脚本与文档相对路径，根绝因当前工作区漂移 `process.cwd()` 导致的致命找不到文件与错误修改）；可组合多技能协同与共享入口中枢模式（MultiSkill Hub Pattern：轻量共享中枢分流至原子叶子技能，配置 2 层交接上限与成环死锁检测）；最小特权工具约束与进程组超时防护（30s 硬超时直接对进程组负 PID `-PID` 下发 `SIGKILL` 拔除卡死进程）；防第三方技能间接提示词注入（XML 结构化隔离检疫与高危指令过滤），以及高可用 TypeScript 技能注册与注水执行引擎。

## ⚡ 1 秒极速集成

在你的项目根目录下执行：

```bash
curl -fsSL https://raw.githubusercontent.com/TrustDec/agent-arsenal/main/install.sh | bash
```

或者直接按需复制到你的项目：
- 复制 `rules/CLAUDE.md` 到你的项目根目录（以及 `./.windsurfrules`, `./.clinerules`, `./.github/copilot-instructions.md`）
- 复制 `rules/.cursorrules` 到你的项目根目录（或将规则作为 `.mdc` 存入 `.cursor/rules/`）
- 复制 `skills/` 到你的 `.agents/skills/`
- 复制 `templates/AGENTS.md` 到你的 `AGENTS.md`

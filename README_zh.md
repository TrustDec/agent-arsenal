- 📜 **事件溯源、CQRS 读写分离与领域驱动事件架构生产级规范 (`rules/event-sourcing-cqrs.md`)**：写入端聚合根（Aggregate Root，强聚焦于业务不变量捍卫与只追加高吞吐写入）与读取端投影物化视图（Projection Read Model，强聚焦于毫秒级宽表关联与多维检索）物理级绝对分离架构、祈使句意图命令（Commands，可能被拒绝）与历史不可变事实领域事件（Domain Events，已发生绝对不可变）核心语义边界、聚合根无副作用纯状态化简函数（`apply(event)`）法则（严禁在命令处理函数中就地修改内部成员，所有状态变更收敛至纯 Reducer；回放历史事件重建状态时严禁二次触发命令校验与网络副作用）、PostgreSQL 只追加事件存储引擎（`stream_id`, `version`, `payload`, `metadata`）与复合主键约束（`PRIMARY KEY (stream_id, version)`）通过底层唯一索引冲突（`23505`）天然实现乐观并发控制（OCC）彻底免疫并发覆盖写偏斜、异步读取端投影消费者严格幂等更新设计（`ON CONFLICT DO UPDATE WHERE last_event_version < EXCLUDED.last_event_version`）与持久化游标位点检查点（`projection_checkpoints`）、海量流聚合根周期性快照机制（$N > 100$ 笔事件）消除历史长流冷启动全量回放延迟、历史不可变事件模式演进与内存 Upcaster 升版转换流水线（$V_1 \to V_2 \to V_3$ 拦截升级杜绝物理污染只追加库）、基于事务性发件箱（Transactional Outbox）与 PostgreSQL WAL 逻辑复制变更数据捕获（CDC with Debezium/`pgoutput`）彻底终结双写不一致灾难、不可变存储下的 GDPR“被遗忘权”合规架构与加密粉碎（Cryptographic Shredding：针对主体密钥 DEK 进行物理覆写擦除，使得历史不可变流中的敏感 PII 密文在保留事件流结构完整性的前提下永世无法解密），以及基于编排式或协同式 Saga 进程管理器的跨聚合长事务逆向补偿设计。
- 🔄 **实时协同、Local-First 本地优先架构与 CRDT 同步生产级规范 (`rules/local-first-crdt-sync.md`)**：零网络延迟本地内存/SQLite 状态即时提交（0ms 乐观 UI 响应）、事务变更源（Origin）强隔离契约（`doc.transact(fn, origin)` 彻底杜绝回环回显广播与 WebSocket 死循环风暴）、撤销重做（UndoManager）严格作用域隔离（`trackedOrigins` 锁定本地用户令牌，全面杜绝协同伙伴远程输入污染本地撤销栈导致的内容幽灵删除灾难）、基于紧凑状态向量（State Vectors）的双向两阶段差量同步（`encodeStateVector` 与 `encodeStateAsUpdate` 替代每次按键百万字节全量重传）、CRDT 墓碑（Tombstones）内存膨胀根除与异步基线快照合并压缩引擎、瞬态感知协议（Awareness Protocol）物理解耦（光标坐标、选区、在线状态与只追加文档历史完全隔离，配置 30 秒心跳自动清理超时僵尸节点，杜绝文档体积失控飙至几百兆）、混合逻辑时钟（Hybrid Logical Clocks, HLC）确定性全序解决物理时钟漂移冲突、持久化客户端 Outbox 发件箱队列（单调递增 UUIDv7 键值与带抖动指数退避重试流水线），以及前端单页应用生命周期监听器销毁闭环（`onScopeDispose` / `useEffect` 彻底消除幽灵连接与内存泄漏）。

## ⚡ 1 秒极速集成

在你的项目根目录下执行：

```bash
curl -fsSL https://raw.githubusercontent.com/TrustDec/agent-arsenal/main/install.sh | bash
```

或者直接按需复制到你的项目：
- 复制 `rules/CLAUDE.md` 到你的项目根目录（以及 `./.windsurfrules`, `./.clinerules`, `./.github/copilot-instructions.md`）
- 复制 `rules/.cursorrules` 到你的项目根目录（或将规则作为 `.mdc` 存入 `.cursor/rules/`）
- 复制 `skills/` 到你的 `.agents/skills/`
- 复制 `templates/AGENTS.md` 到你的 `AGENTS.md`
